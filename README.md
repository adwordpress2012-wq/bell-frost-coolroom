# Bell Frost Coolroom

Fresh one-page rebuild for `bell-frost-coolroom`, built with Next.js App Router, TypeScript and clean CSS.

## Notes

- Static marketing website only, with no backend connection.
- Contact form is a non-submitting mockup.
- Real Bell Frost logo, licensed hero photography, branded van photography and SCW/Micah embed are marked in code comments for later replacement.
- DOS Commercial Template Rules v1 direction applied: premium commercial layout, realistic photo-style placeholders only, no cartoon characters, no SVG workers, no vector vans and no mascot-style hero illustration.

## Commands

```bash
npm install
npm run lint
npm run typecheck
npm run build
```
